Why LowRankArena

Compression claims need a shared coordinate system.

Low-rank studies often differ in model vintage, task versions, budget definitions, precision, and inference setup. LowRankArena fixes those axes and releases the checkpoints and normalized outputs needed to audit each comparison.

The primary leaderboard focuses on uniform-precision SVD. Hybrid, remapping, runtime-adaptive, and structured-pruning results are separated into clearly labeled comparison or audit tracks.

Quality

Rankings are conditional.

Backbone, compression budget, and metric group can each change which recipe looks strongest.

Stability

MCQ can hide perplexity collapse.

Answer-selection accuracy may remain plausible after the model's generative distribution degrades sharply.

Systems

Nominal savings are not endpoint speed.

Factorized operators help some compute-bound stages but can lose ground once decode and backend overhead dominate.

Reproduce

Start with a registered checkpoint, then run one shared path.

The repository exposes separate accuracy, active-memory, and vLLM serving entrypoints. Normalized outputs share one project-owned top-level schema.

Checkpoint registry ↗ Result schema ↗ Audit reproductions ↗
quick start
conda env create -f environment.yml
conda activate lowrankarena

# Accuracy
python scripts/run_eval.py \
  llama31-8b-svdllm-v1-update-0.6 \
  --suite accuracy/mcq

# Active GPU memory
python scripts/run_memory.py \
  llama31-8b-svdllm-v1-update-0.6

# vLLM speed
python scripts/run_speed.py \
  llama31-8b-svdllm-v1-update-0.6
