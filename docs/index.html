Reproduce

Start with a registered checkpoint, then run one shared path.

The repository exposes separate accuracy, active-memory, and vLLM inference entrypoints. Normalized outputs share one project-owned top-level schema.

Checkpoint registry ↗ Result schema ↗ Audit reproductions ↗
quick start
conda env create -f environment.yml
conda activate lowrankarena

# Accuracy
python scripts/run_eval.py \
  llama31-8b-svdllm-v1-update-0.6 \
  --suite accuracy/mcq

# Active GPU memory
python scripts/run_memory.py \
  llama31-8b-svdllm-v1-update-0.6

# vLLM speed
python scripts/run_speed.py \
  llama31-8b-svdllm-v1-update-0.6
