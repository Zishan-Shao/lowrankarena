# `checkpoints/vllm/`

This directory documents the layout for materialized vLLM-compatible wrapper checkpoints.
	
These wrapper directories are derived artifacts, not source checkpoints. The runtime now defaults to an external cache under `~/.cache/lowrankarena/vllm`, so this folder should only contain intentionally archived wrappers that are worth checking in.

## Intended Content

- Wrapper models created from released checkpoints in [`checkpoints/index.csv`](../index.csv).
- Compatibility shims such as SVD-LLM LLaMA wrappers that preserve low-rank weights while exposing the interfaces required by vLLM.
- Files in this directory are generated by the adapter path in [`src/vllm/`](../../src/vllm/README.md) or by explicit wrapper-preparation scripts.

## Notes

- Keep benchmark outputs in [`results/`](../../results/README.md), not here.
- Keep registry metadata in [`checkpoints/index.csv`](../index.csv), not in sidecar prototype indexes.
